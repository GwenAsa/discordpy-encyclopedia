# Contributing

Thanks for your interest in improving the discord.py Encyclopedia!

## How to contribute

1. Fork the repository.
2. Create a branch: `git checkout -b fix/typo-in-embeds`
3. Make your changes.
4. Commit: `git commit -m "fix: correct field limit in embeds section"`
5. Push: `git push origin fix/typo-in-embeds`
6. Open a Pull Request.

## What we welcome

- 🐛 Bug fixes (typos, broken links, wrong code)
- ✨ New sections (missing APIs, more examples)
- 📝 Better explanations for beginners
- 🌍 Translations

## What we don't accept

- ❌ Spam or self-promotion
- ❌ Unrelated content
- ❌ AI-generated content without review

## Style guide

- English only
- Use tables for API references
- Every new concept needs a runnable example
- Keep lines under 120 characters
